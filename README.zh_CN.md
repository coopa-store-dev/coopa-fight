# 库巴格斗

三个键的全家格斗:选一个家人,面对面站着打。● 轻拳打中的一瞬间马上按 ▼ ●,大招就接上了——
黑屏特写、喊招式名、掉三成血,对方被打懵,得狂按才挣得开。不拼手速,拼猜对方下一下出什么、看准了挡。

- **和电脑打**:一个人也能玩,依次打另外三个家人(简单 → 普通 → 厉害),三关都赢就通关,选人页这个人头上戴皇冠。
- **两人联机**:两个人各拿一张 Coopa 卡,面对面对战。

一回合 60 秒,血打空就输,到时间血多的赢(一样多就重打这一回合);先赢 2 回合的人赢。

## 出招表

| 按法 | 招 |
|---|---|
| ● | **拳**:出手快(0.18–0.24 秒打到),伤害小 |
| ▲ | **重击**:抡 0.55–0.65 秒,伤害大,能砸开防御(被砸开的人晕 1 秒) |
| ▼ | **防**:举盾 0.6 秒(奶奶 0.8 秒),挡住拳和小招;按着 ▼ 撑到 1.2 秒。盾刚举起来 0.2 秒内被打到就**弹开** |
| ▼ ▲ | **小招**:从盾后面出,不花气;出完 1 秒内不能再出 |
| ● 打中后 ● | 再一拳,最多三连 |
| ● 打中后 ▲ | **连段重击**:不用抡,一定中 |
| ● 打中后 ▼ ● | **大招**:花 1 格气 |
| 晕了 | **狂按**随便哪个键挣脱 |

- **三种动作互相克制**:拳打断刚开始抡的重击(抡的前 0.3 秒);重击砸开防御;盾挡住拳,出拳的人多僵 0.5 秒,挡住的一方可以反打。
- **弹开(看准了挡)**:对方的招快打到时才按 ▼,盾刚举起来不到 0.2 秒就挨到,这一下就弹开了——重击、肩撞也弹得开。
  打过来的人僵 1 秒,弹开的人马上能动、白拿 0.4 格气,接着按 ● 就是连招的下一拳,▼ ● 能直接出大招。
  乱按 ● 的人最怕这个:连完三拳总要重新起手,看准那一拳按 ▼。
- **连招**:拳打中后对方僵 0.6 秒,这段时间里按的下一个键接上。可以提前按,提前按的不管打没打中都照样出——拳打空了,后面的 ▼ ● 就是举盾加一拳,会被反打。
- **▼ ● 要「嗒嗒嗒」快快点三下**:按着 ▼ 时按 ● 不算,要先松开 ▼ 再按 ●。▼ 后 0.35 秒内按的 ▲ / ● 算小招 / 大招;这个 ▼ 举起的盾还在时按 ▲(按着 ▼ 再按 ▲)也是小招。
- **气**:3 格。打中、挨打、挡住、弹开都涨,挨打涨得最多;血落后的一方挨打再多涨一点。气带到下一回合。
- **大招打中**:两张卡一起放 1.5 秒特写(这时计时停、按键不算),掉 300 血(满血的三成),对方晕 2 秒。
  晕了狂按:每按一下早醒 0.16 秒,一秒最多算 6 下。晕着挨一套就醒;醒来的 0.3 秒里不收键、也不挨打。
- **不会晕了又晕**:从被打晕到醒了能动为止,不会再晕,也挨不到大招(对他按 ● ▼ ● 只出拳)。挨打僵着的人只会被这一套连招里的下一下打中,另起的招打不中。

## 四个角色

| 角色 | 手感 | ▼ ▲ 小招 | ● 打中后 ▼ ● 大招 |
|---|---|---|---|
| 库巴 | 拳最快,血略少(950) | 弹弓:弹珠飞过去,打中对方僵住,能接拳 | 影分身乱打:几个库巴轮着揍 |
| 库巴爸爸 | 重击抡得最快、最痛,拳慢一点 | 肩撞:冲过去撞,能砸开防御(对方只僵住,不晕) | 铁笼大锤:把对方关进铁笼一锤砸下,晕的时候在笼子里狂按 |
| 库巴奶奶 | 盾举得久 | 锅盖飞盘:锅盖飞出去再飞回来,打两下 | 念叨风暴:满屏念叨的字砸下来,最后擀面杖一下 |
| 库巴爷爷 | 动作最慢,拳最痛 | 太极推手:摆 1 秒架势,对方这时打过来就接住推回去(对方僵住,能接连招) | 太极·排山倒海:一掌把对方推出屏幕又弹回来 |

- 爷爷的太极是反击:对方不打,架势收了就露出破绽。
- 联机断线不怕:这一回合重来,比分、气都留着。

## 开发

需要外壳接口 2(`kit_api = 2`,`kit_link.h`)和 SDK 4。

- `make -C tests`:规则、招式、联机、电脑对手、存档、图的宿主测试;`test_balance` 打几千场统计数值
  (四人两两胜率、小孩对大人、死打法、一场多长)。给 `COOPA_SHELL=外壳目录` 时再测一遍语音解码。
- `tools/gen_lines.py`:重新生成四个角色的语音(要 edge-tts 和 ffmpeg)。
- `tools/gen_art.py`:把 `art/*.txt` 的字符画重新生成成常量图(`src/fight_art.c`,LVGL 直接从游戏块读,不占堆)。
- `tests/sim_cpu.py`、`tests/sim_duo.py`:在桌面模拟器里和电脑闯关(两个键叠着按也在这里测)、两张卡对战(中途断线)。
- `coopa run`:浏览器里玩;打开它打印的 `duo.html` 可以一页两张卡对战。
- `coopa check`:和商店一样的检查。
- 数值都在 `src/fight_moves.c` 的出招表和 `src/fight_sim.h` 的宏里。
